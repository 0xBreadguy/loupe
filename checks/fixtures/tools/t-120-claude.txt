 HOW THIS IS COUNTED ─────────────────────────────────────────────────────────────────────────────────────────────────
 Time adds up each call's own length. Calls in a thread can overlap; counted once, they come to 28h on the clock.
 Recap's 'tools' hours are counted another way.

 2 calls never ended and add no time.

 A line like "cd app && cargo test | tail" is one call, named for its main program, cargo: its time, failure and exit
 code are the whole line's. 71% of command lines ran two or more programs on the list. Programs are named from a list
 of 75 common ones; a command with none of them is "not on the list".

 Only program and tool names and exit codes are read. Numbers may be cached in your cache folder; nothing is sent.
