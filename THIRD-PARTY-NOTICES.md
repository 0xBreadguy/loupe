## uucode

https://github.com/jacobsandlund/uucode, as vendored in OpenTUI v0.8.3 (`uucode-opentui` inside `packages/native/src/vendor/zig-deps.tar.gz`). From it: the grapheme break rules ported into `crates/core/src/cluster.rs`, and the rules by which `checks/scripts/generate-clusters.ts` derives each code point's properties for `crates/core/src/cluster_tables.rs`. The license is that archive's `uucode-opentui/LICENSE.md`.

Its license names two more files, for a UTF-8 decoder by Bjoern Hoehrmann and for Unicode data. Neither file is in the vendored archive. Nothing of that decoder is in this repository, and the Unicode data has its own entry below.
